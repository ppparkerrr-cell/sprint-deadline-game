# СПРИНТ: ДЕДЛАЙН

Русскоязычная браузерная игра-симулятор управления проектом. Распределяйте специалистов по задачам на диаграмме Ганта, следите за сроком и бюджетом, избегайте перегрузки команды и реагируйте на случайные события.

## Возможности

- сотрудники с разной скоростью и стоимостью;
- задачи с зависимостью от календарного плана;
- перерасход бюджета и прогноз стоимости;
- замедление при одновременной работе сотрудника над несколькими задачами;
- случайные положительные и отрицательные события;
- адаптивный интерфейс, анимации и локальный рекорд.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте `http://127.0.0.1:3000`.

## Сборка

```bash
npm run build
```

Игра создана с самостоятельным визуальным стилем и оригинальным набором контента.
